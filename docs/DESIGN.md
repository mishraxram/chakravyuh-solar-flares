# DESIGN

Direction: a forensic evidence desk — manila paper, black ink, evidence tags. Calm, precise, monospace for anything that is evidence.
Signature element: the amber "evidence tag" chip that carries each file's SHA-256 hash (chain-of-custody stamp).

| Name | Hex | Meaning |
|---|---|---|
| ink | #14161A | text, primary buttons |
| paper | #F4F1EA | page background |
| tag | #E0A526 | evidence tags, hashes, highlights |
| flag | #C2362B | suspicious events, TAMPERED |
| match | #2F7D4F | hash MATCH, safe |
| muted | #6B6F76 | secondary text |

Fonts: IBM Plex Sans (UI) + IBM Plex Mono (logs, hashes, timestamps).
